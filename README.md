## 📌 Introduction
This repository contains **C++ programs** that demonstrate the fundamental concepts of **Object-Oriented Programming (OOP)** such as **classes, encapsulation, inheritance, polymorphism, and abstraction.**  

It is meant for **students and beginners** who want to strengthen their understanding of C++ OOP concepts through hands-on coding.

---

## 🛠️ Key Topics Covered
- **Classes & Objects** → Create and use objects from user-defined classes  
- **Encapsulation** → Data hiding using access specifiers (`private`, `protected`, `public`)  
- **Inheritance** → Reusing and extending code with single, multiple, and multilevel inheritance  
- **Polymorphism** →  
  - Compile-time (function & operator overloading)  
  - Runtime (virtual functions)  
- **Abstraction** → Interfaces and abstract classes using pure virtual functions  
- **Other Concepts** → Constructors, destructors, friend functions, templates
